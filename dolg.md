# Технический долг SmartNotes-ai

В данном документе перечислены ключевые направления по устранению технического долга, улучшению архитектуры и оптимизации производительности приложения.

---

## Актуальный технический долг

### 1. Синхронизация медиафайлов (Background Media Sync)
* **Текущее состояние**: При отсутствии сети или сбое загрузки медиафайлы сохраняются локально в IndexedDB как бинарные Blob-объекты (`local-inline`).
* **Проблема**: Отсутствует автоматический фоновый механизм для синхронизации локальных Blob-файлов с облачными хранилищами при восстановлении соединения.
* **Решение**: Реализовать Background Sync Worker или локальную очередь загрузки, которая отслеживает записи `local-inline` в IndexedDB и пытается отправить их в облако при стабильном подключении.

### 2. Протокол совместного редактирования (CRDT Migration)
* **Текущее состояние**: Сохранение заметок и страниц использует REST-запросы и периодическую отправку изменений (patches).
* **Проблема**: В режиме совместного редактирования высок риск конфликтов данных и перезаписи изменений при одновременной работе нескольких пользователей.
* **Решение**: Мигрировать на протокол бесконфликтного слияния (CRDT), внедрив библиотеки (например, Yjs или Automerge) для синхронизации состояния редактора в реальном времени.

### 3. Абстракция хранилищ медиа (Storage Provider Interface)
* **Текущее состояние**: Код загрузки/скачивания медиафайлов содержит ветвление логики (Google Drive, Supabase Storage, IndexedDB) прямо в вызывающих функциях.
* **Проблема**: Добавление новых провайдеров хранения или изменение текущих требует изменения множества разрозненных обработчиков.
* **Решение**: Описать интерфейс `StorageProvider` со стандартными методами `upload`, `download`, `delete` и реализовать конкретные адаптеры для каждого типа хранилища.

## Выполненные задачи

### 1. Оптимизация ИИ-анализа и устранение избыточных вызовов
* **Результат**: Реализовано синхронное сопоставление хешей содержимого на стороне бэкенда и Edge-функции. Если контент не изменялся, вызовы к LLM полностью блокируются.
* **UI-синхронизация**: При отправке запроса на анализ клиентский кэш React Query мгновенно переводится в состояние `analyzing`, активируя фоновый опрос и корректную индикацию процесса в редакторе.

### 2. Принудительный JSON-режим для ответов ИИ
* **Результат**: Все запросы к OpenRouter переведены на использование параметра `response_format: { type: "json_object" }`, гарантируя корректный формат без сбоев из-за markdown-разметки.

### 3. Замена сброса пароля через email на прямую смену
* **Результат**: Устранены ошибки сбоя верификатора PKCE при восстановлении пароля на SSR-платформе. В настройки встроен интерфейс прямой смены пароля внутри сессии.

### 4. Настройка конфигурации сборки Next.js и монорепозитория
* **Результат**: Удалены дублирующие файлы `package-lock.json` из подпапок `SmartNotes-web` и `backend`, все зависимости теперь обслуживаются единым lock-файлом в корне воркспейса. Настроен параметр `turbopack.root` в `next.config.ts` для поддержки монорепозитория.
