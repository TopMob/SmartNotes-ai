# Хранение медиа (BYOS: Bring Your Own Storage)

Концепция BYOS означает, что SmartNotes не хранит файлы пользователей (изображения, вложения) на своих серверах. Все тяжелые данные лежат в личном облаке пользователя, что снижает затраты на инфраструктуру и повышает приватность.

Основная реализация находится в модуле `features/media-byos`.

---

## 1. Абстракция Storage Provider

В системе нет жесткой привязки к Google Drive. Вся логика работы с файлами скрыта за интерфейсом `StorageProvider`, который описывает методы:
- `upload(file: File): Promise<MediaDescriptor>`
- `delete(mediaId: string): Promise<void>`

На данный момент реализованы провайдеры для **Google Drive** и локальный **IndexedDBStorageProvider** (для оффлайна).

В самой заметке (`note_media`) хранится только легкий объект `MediaDescriptor`, содержащий ссылку на скачивание файла из облака.

---

## 2. Загрузка через Proxy (Next.js API)

Из-за ограничений CORS и необходимости сжатия файлов, загрузка картинок не идет напрямую из браузера в Google Drive.
1. Клиент выбирает картинку в Tiptap.
2. Файл сжимается (например, до ширины 1920px).
3. Файл отправляется на Next.js API route (`/api/media`).
4. Сервер, используя Google OAuth токены пользователя (`NEXT_PUBLIC_GOOGLE_CLIENT_ID`), выполняет загрузку файла в папку "SmartNotes" на его Google Drive.
5. Сервер возвращает клиенту URL картинки, который вставляется в редактор.

---

## 3. Background Media Sync (Оффлайн загрузка)

Одной из главных проблем PWA-приложений является невозможность загрузить картинку в облако без интернета. Эта проблема решена через фоновую синхронизацию.

1. Если пропал интернет и пользователь вставил картинку, срабатывает `IndexedDBStorageProvider`. 
2. Картинка сохраняется в локальную базу данных браузера (как Blob), а в Tiptap вставляется временная ссылка (base64/blob url) типа `local-inline`.
3. Запускается фоновый воркер `syncLocalMedia()`.
4. Он слушает события `online` (восстановление сети) и `visibilitychange` (разворачивание вкладки).
5. При появлении сети воркер находит все `local-inline` файлы в локальной БД, поштучно загружает их в Google Drive через Proxy, заменяет ссылки в тексте заметок на реальные URL, после чего удаляет Blob-объекты из IndexedDB браузера.
