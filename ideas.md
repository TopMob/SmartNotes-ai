# SmartNotes AI — Перспективные идеи развития

> Спецификация и концепт-макет интерактивного ИИ-ассистента для умной работы с заметками (BrainEngine Co-Pilot).

---

## 🧠 1. Концепт: ИИ-Чат (Semantic RAG Co-Pilot)

Интерактивный чат-интерфейс (аналог Gemini в Google Workspace / Sidepanel в Gmail), который выступает в роли умного компаньона, помогающего пользователю ориентироваться в хаосе мыслей, структурировать проекты и находить неочевидные связи между заметками.

### Основная идея:
Ассистент работает **строго на контексте базы знаний пользователя (заметках)**. Он не придумывает информацию из интернета, а извлекает, синтезирует и структурирует данные, созданные самим пользователем, с обязательным цитированием первоисточников.

## 🛠️ 2. Сценарии использования (UX Scenarios)

### Сценарий А: «Наведи порядок в моих мыслях»
* **Запрос пользователя:** *«Слушай, у меня тут полная неразбериха. Помоги структурировать последние мысли по запуску проекта X.»*
* **Действие ИИ:** 
  1. Выполняет семантический поиск по ключевым концептам последних заметок.
  2. Группирует разрозненные мысли в логические блоки (например: Цели, Задачи, Риски, Идеи).
  3. Выдает структурированный дайджест со ссылками на конкретные заметки.
  4. Предлагает целевые действия: *«Создать папку "Проект X" и перенести туда эти 5 заметок?»*.

### Сценарий Б: «Синтез и поиск связей»
* **Запрос пользователя:** *«Какие темы пересекаются у меня в заметках по психологии и в конспектах книг по менеджменту?»*
* **Действие ИИ:** Находит пересечения по тегам и векторной близости, выделяет общие паттерны (например, "мотивация сотрудников" и "поведенческая психология") и строит краткий конспект-выжимку.

### Сценарий В: «Быстрый вопрос по базе знаний»
* **Запрос пользователя:** *«Какой пароль от Wi-Fi в офисе я записывал на прошлой неделе?»* или *«Когда дедлайн по сдаче макета?»*
* **Действие ИИ:** Мгновенно извлекает точный кусок текста из нужной заметки и подсвечивает его в ответе.

## 📐 3. Архитектура и мировые практики (Technical Implementation)

Чтобы чат работал быстро, точно и безопасно, система строится по архитектуре **RAG (Retrieval-Augmented Generation)** с использованием лучших индустриальных решений:

```
[ Пользовательский запрос ] 
         │
         ▼
[ Расширение запроса (Query Expansion) ] 
         │
         ├──────────────────────────────────────────┐
         ▼ (Семантика)                              ▼ (Ключевые слова)
[ Векторный поиск (pgvector) ]              [ Полнотекстовый поиск (FTS) ]
         │                                          │
         └────────────────────┬─────────────────────┘
                              ▼
                 [ Гибридное ранжирование ]
                              ▼
            [ Извлечение релевантных чанков заметок ]
                              ▼
             [ Системный промпт (LLM OpenRouter) ]
                              ▼
              [ Ответ в чате с цитированием ]
```

### 3.1. Векторизация и Хранение
* **Supabase pgvector**: Каждая заметка разбивается на смысловые чанки (Chunks). Для каждого чанка генерируется векторный эмбеддинг через легковесную модель (например, `text-embedding-3-small` от OpenAI или локально через `xenova/all-minilm-l6-v2` для PWA/offline режима) и сохраняется в таблице `note_embeddings`.
* **Фоновый пайплайн**: Векторизация запускается автоматически в фоновой очереди `ai-queue` при сохранении изменений в заметке.

### 3.2. Гибридный поиск (Hybrid Retrieval)
Для максимальной точности объединяются два метода:
1. **Семантический векторный поиск** (понимание контекста, синонимов и ассоциаций).
2. **Полнотекстовый поиск Postgres FTS** (точный поиск редких имен, кодов, паролей и аббревиатур).
Результаты объединяются с помощью алгоритма **RRF (Reciprocal Rank Fusion)**.

### 3.3. Генерация с жесткими ограничениями (Guardrails)
* **Промпт с привязкой**: Системный промпт LLM обязывает модель отвечать *только* на основе переданных в контексте заметок. Если информации нет в базе знаний, модель прямо заявляет: *"У меня нет заметок на эту тему"*.
* **Интерактивные цитаты (Footnotes)**: Любой факт в ответе сопровождается интерактивной ссылкой на заметку: `[Название заметки](noteId)`. Клик по ссылке мгновенно открывает заметку в редакторе `EditorOverlay`.

### 3.4. Интерактивные агенты (Agentic Actions)
ИИ-чат не только отвечает текстом, но и возвращает структурированный JSON с предлагаемыми действиями (UI Actions), которые пользователь может выполнить в один клик:
* `createFolder(name)` — создать папку
* `moveNotesToFolder(noteIds, folderId)` — сгруппировать заметки
* `addTagsToNotes(noteIds, tags)` — проставить теги
* `createTaskReminder(noteId, date)` — запланировать задачу

## 📈 4. План поэтапной реализации

1. **Фаза 1: Инфраструктура БД (Supabase)**
   - Подключение расширения `pgvector` в Supabase.
   - Создание таблицы `note_embeddings` со связью `cascade on delete` с `notes`.
   - Написание RPC-функций гибридного поиска.

2. **Фаза 2: Пайплайн эмбеддингов**
   - Интеграция генерации векторов в существующую фоновую очередь `ai-queue.ts`.

3. **Фаза 3: API Чат-Эндпоинт**
   - Роут `/api/ai/chat` с поддержкой стриминга (`Server-Sent Events / ReadableStream`) для посимвольного вывода ответа OpenRouter.

4. **Фаза 4: UI Чат-Панель (Sidebar)**
   - Создание выдвижной боковой панели (Sheet) с историей переписки.
   - Поддержка интерактивных ссылок-сносок на заметки и кнопок быстрых агентских действий.
